# Blood Cell Classification using PyTorch

An end-to-end Deep Learning project for multi-class classification of peripheral blood cell images into four distinct categories using PyTorch.

---

##  Project Overview
Automated identification of blood cell subtypes is vital for accelerating diagnostic workflows in hematology and clinical pathology. This project implements a Convolutional Neural Network (CNN) pipeline to classify single-cell microscopic images into:

- **Eosinophils** (~2,497 images)
- **Lymphocytes** (~2,483 images)
- **Monocytes** (~2,478 images)
- **Neutrophils** (~2,499 images)

**Total Dataset Size:** 9,957 images.

---

##  Dataset
The dataset used in this project is the **Blood Cell Images** dataset.
- Available on Kaggle: [Blood Cell Images Dataset (by Paul Mooney)](https://www.kaggle.com/datasets/paultimothymooney/blood-cells)
